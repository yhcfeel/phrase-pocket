# 词库校对说明

按用户提供的四张图片顺序整理，共 104 条。第 1～4 张分别有 29、25、26、24 条；同一行的易混词分成独立卡片。sb. = 某人，sth. = 某物／某事；A/B/C 是可替换成实际内容的占位符。

中文释义为重新概括。下面的引用指向对应词条、核心词义或语法资料；普通组合与从句结构不表示词典把整个表达单独列为习语。关键疑点在线对照了 Cambridge、Oxford、Collins、Merriam-Webster 和 American Heritage 的相关资料。并非每条常见组合都在词典中有独立词条。

## 需要特别留意的修订

- million = 百万；billion 在现代常用英语中 = 十亿。
- be know for 改为 be known for；tricks of trade 补为 tricks of the trade。
- go on to do 表示接着做另一件事，go on doing 才表示继续做同一件事。
- ensure A for B 本身可成立，明确记为 ensure sth. for sb.，不把它错改为其他动词。
- be intend to do 改为 be intended to do（旨在／被设计用来）；与 intend to do（打算）分开。
- allow for 保留“使……成为可能”义，同时补充“考虑到、留出余地”。Merriam-Webster 的 allow for 词条列有这些义项，原笔记这一义并非一定错误。
- address a problem 是着手处理／应对，不表示已经成功解决。
- to top it all off 可用于特别好的事，也可用于更糟的事。
- run the length of 是沿整个长度延伸、贯穿，不只表示“长度为”。
- from A to B 表示起止或范围，单靠该结构不能推出范围很大。

## 手写推定和语境边界

1. 第 1 张的 what is now …：英文按 now 辨认，记为“如今是……的事物／地方”。旁注似有“新的东西／情况”，与 now 不一致；若原意是 what is new，意思应为“新的事物”，而 What's new? 常问“有什么新鲜事？”。应用选择前一种读法，无法凭截图确认原文语境。
2. 第 3 张 take my cu… from 按中文“得到启示”推定为 take one's cue from。
3. 第 3 张 be entrenched in 按“根深蒂固”确认词形。
4. 第 4 张 the role … has in … 规范为更便于活用的 the role … plays in …；没有把原 has 一概判为语法错误。
5. what it is / what it was / what (= the thing(s) that) 是从句结构，只在相应句法中使用；不是在所有场合都机械替换。
